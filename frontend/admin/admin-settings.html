Role Permissions

Admin Capabilities

  • Change own password
  • Add and remove moderators
  • Manage all users (edit, delete, ban)
  • Configure system settings and alerts
  • Manage ML models and training
  • View all system logs and audit trails
  • Monitor API usage and performance
  • Full access to all disaster monitoring features

Moderator Capabilities

  • Change own password
  • View and manage regular users
  • Configure alert thresholds and notifications
  • View system logs (read-only)
  • Monitor API status
  • Access all disaster monitoring features
  • Cannot add/remove other moderators
  • Cannot manage ML models or system config
